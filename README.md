# Choosing Faculty Titles

A static GitHub Pages copy of the Whiting School of Engineering Faculty Title Guide, updated November 16, 2026. It includes 26 decision questions, 25 endpoints, and 18 distinct directory titles. Every endpoint and directory title includes criteria. Next steps include dossier requirements, voting guidance, checklist and referee-letter links, the named Faculty Affairs contact, and SmartPath.

Public site: https://aubrey-po.github.io/Choosing-Faculty-Titles/

## Local preview

Run a simple local server (the guide uses JavaScript modules):

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

This repository is configured as a static site. GitHub Pages will serve the root-level `index.html` file automatically when the branch is set to `main` and the source is the root folder.

The guide links the full WSE policies and procedures and routes tenure-track help to Sheri Green at wsetenureactions@jh.edu. It does not collect candidate information.

Source notes: the new research-compensation checkpoint at step 36 is included before step 37, correcting the source's otherwise unreachable route. Internal JHU courtesy appointments now use the source's matching-title email notification or different-title directory referral. The previous dossier placeholders are removed. GELL referrals use the user-supplied address wsepostdocappts@jhu.edu.
