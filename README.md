# Choosing Faculty Titles

A static GitHub Pages site for a practical faculty title guide.

## Local preview

Open `index.html` directly in a browser or run a simple local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

This repository is configured as a static site. GitHub Pages will serve the root-level `index.html` file automatically when the branch is set to `main` and the source is the root folder.
