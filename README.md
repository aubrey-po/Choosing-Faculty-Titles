# Choosing Faculty Titles

The GitHub Pages copy of the Whiting School of Engineering Faculty Title Guide, updated November 17, 2026. It contains 16 question screens, 25 endpoints, and 18 distinct directory titles, with criteria, privileges, and applicable appointment procedures from the revised source.

Public site: https://aubrey-po.github.io/Choosing-Faculty-Titles/

## Local preview

Serve the repository root with a local HTTP server, for example `python -m http.server 8000`, then visit `http://localhost:8000`.

## GitHub Pages

GitHub Pages serves the root-level `index.html` from the `main` branch. The site does not collect candidate information.

The November 17 revision introduces multiple-choice criteria, a visiting-appointment checkpoint, the updated compensation and multi-year teaching checks, and revised JHU secondary-appointment guidance. The user clarified that the student/postdoc check should precede the engineering-degree check. The omitted destination for the some-teaching-experience option is Assistant Teaching Professor, matching its criterion.

Faculty Affairs: wseacademicappta@jhu.edu. GELL: wsepostdocappts@jhu.edu. Tenure-track help: wsetenureactions@jh.edu.

The full policies and procedures, SmartPath, dossier checklists, and referee-letter templates remain linked where applicable.
